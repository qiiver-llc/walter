# Laugh sounds

Played when Walter writes `[laugh]` (a random `soft-*` clip) or `[laugh:big]`
(a random `big-*` clip); never the same clip twice in a row. Each clip was
cut from the Freesound HQ preview, converted to mono 22050 Hz 16-bit WAV,
high-passed at 70 Hz, trimmed, normalised to about -17 dB active RMS (Walter's
piper voice is about -14 dB) with a -1 dBFS peak cap, and given short fades.

All sources are **CC0 1.0 (public domain dedication)**:
https://creativecommons.org/publicdomain/zero/1.0/
